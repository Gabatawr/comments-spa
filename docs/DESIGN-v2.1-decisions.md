## 1. Контракт данных: цитаты (аддитивно)

| Слой | Значение |
|---|---|
| JSON (`CommentDto`) | `quotedText: string \| null` — camelCase, необязательное |
| PostgreSQL | `comments.quoted_text text NULL` |
| MySQL (`db/schema.sql`, MySQL Workbench) | `quoted_text TEXT NULL` |
| GraphQL | `Comment.quotedText: String` (появляется автоматически из DTO, явный `Field` не обязателен) |
| WebSocket `comment.created` | входит в `CommentDto` автоматически |

Поле **не ломает** `docs/API-v2.md`: это необязательное дополнение к `CommentDto`, старые записи → `null`.

### 1.1 Алгоритм снимка (бэкенд, при `parentId != null`)

1. Загрузить родителя (`ICommentRepository.GetByIdAsync(parentId)`).
2. Источник — `parent.TextPlain` (он уже без тегов, entities раскрыты `HtmlSanitizer`).
3. Схлопнуть пробелы: `Regex.Replace(s, @"\s+", " ").Trim()`.
4. Если `length <= 160` — хранить как есть, **без** многоточия.
5. Иначе: взять первые 160 символов; отступить назад до последнего пробела (если он не в позиции 0); если пробела нет — жёсткий рез на 160; добавить `…` (U+2026).
6. Записать в `Comment.QuotedText`. Пустой plain → `null`. `parentId == null` → `null`.
7. Максимальная длина сохранённого значения — 161 символ. Класс-хелпер: `QuoteSnapshot`.

**Инварианты:** снимок никогда не содержит **разметки** (источник — уже очищенный `TextPlain`; raw-теги до него не доходят: `HtmlSanitizer` их нейтрализует, а POST с raw `<script>`/`<img onerror>` → 400). Замороженный контракт не меняется.

**Тонкость (решено — вариант A):** санитайзер раскрывает entities, поэтому plain-текст `&lt;script&gt;alert(1)&lt;/script&gt;` даёт снимок, буквально содержащий подстроку `<script>alert(1)</script>`. Это **легитимный плоский текст**, а не разметка. Жёсткая зачистка `<`/`>` в `QuoteSnapshot` **не делается** (искажала бы обычный текст «a < b» и отклонялась бы от §1.1). Гарантия безопасности — экранирование при выводе (§1.2): цитата рендерится только интерполяцией, `innerHTML` запрещён. Проверяется на двух уровнях: (1) unit — снимок не содержит разметки; (2) DOM — внутри `.comment-quote` ноль элементов script/img.

### 1.2 Контракт рендера (фронтенд)

- Только интерполяция `{{ comment.quotedText }}` (Angular экранирует сам). **Никогда** не `innerHTML`/`bypassSecurityTrust*` для цитаты.
- Рендерится **над** телом ответа, только если `quotedText` непустой.
- Разметка: контейнер `.comment-quote` + текстовый узел `.comment-quote-text`.
- CSS: `border-left: 2px solid var(--quote-bar)`, `padding-left: 9px`, `color: #848b99`, `font-style: normal` (**не курсив**).
- Полоса стоит **на том же левом уровне, что и обычный текст тела** (это не двойной отступ вложенности).
- Однострочный кламп как в образце: `white-space: nowrap; overflow: hidden; text-overflow: ellipsis;`

## 2. Шапка записи — измеренные константы

Образец: карточка `x 32..881` (белая, `#ffffff`), горизонтальные поля карточки **32 px**, полоса-шапка **56 px** высотой, левый край шапки уровня: **64 / 96 / 128** px (глубина 0/1/2).

| Элемент | Спецификация |
|---|---|
| Шапка | высота **56 px**, фон по **чётности глубины**: чётная → `#f5f6f7`, нечётная → `#f5f7fb`. Измерено по образцу: глубина 0 `#f5f6f7`, 1 `#f5f7fb`, 2 `#f5f6f7` (обе краски из палитры). Тени у карточек отсутствуют, 32 px над шапкой — фон самой карточки (`#ffffff`) |
| Аватар | круг **40 px**, инициалы белым, светлое кольцо **2 px** (`#ffffff`) |
| Имя | жирное, `#0a1833`, **17 px** |
| Дата | `#848b99`, **15 px**, строго `DD.MM.YY в HH:MM` |
| 4 иконки | **SVG**, `currentColor` = `#7b95c8`, **20 px**, шаг **~16 px**, сразу после даты, порядок: `#` · закладка · ответ(↳) · инфо(ⓘ) |
| Голосование | прижато вправо: `↑` · `0` · `↓`, `#848b99`, некликабельно (`aria-hidden`) |
| Тело | `#475266`, **16 px**, `line-height ~1.55` |
| Вложенность | отступ **32 px** на уровень; шапка ребёнка сдвинута так же, как тело |
| Линия вложенности | `2px solid #e0e2e6` на контейнере детей (DESIGN §5; также требование существующего Playwright-чека) |
| Полоса цитаты | **2 px**, `#b3c2e1` (измерено в образце), текст `#848b99` |

### 2.1 Поведение иконок

| № | Иконка | Действие |
|---|---|---|
| 1 | `#` | якорь: скролл к записи + `#comment-<id>` в URL (не перезагрузка) |
| 2 | 🔖 закладка | клиентская, `localStorage` (`comments:bookmarks`) |
| 3 | ↳ ответ | раскрывает форму ответа (тот же output `reply`, что и раньше) |
| 4 | ⓘ инфо | всплывающая карточка автора: имя, e-mail, IP, сайт (ссылка, только http/https) |

`data-testid="reply-button"` переносится на иконку ответа (регресс не ломаем).
E-mail, IP и «домашняя страница» **не выводятся как текст** в шапке.

## 3. Честные расхождения: DESIGN-v2 / пользовательская постановка ↔ образец

Фиксируем заранее, чтобы приёмка их не «открывала заново»:

1. **§5 «отступ ~40 px» → измерено 32 px** (шапки 64→96→128). Образец — главный ориентир, реализуем **32 px**.
2. **§5 «линия вложенности слева `#e0e2e6`»** — в образце сплошной линии вне шапок нет (программно: нет колонки `#e0e2e6` длиной > 30 px вне полос шапок). Линию **оставляем** (контракт §5 + существующий Playwright-чек `cascade has a left quote bar`), но делаем тонкой `2px #e0e2e6`, чтобы визуально почти не отличалась от образца.
3. **§4 «полоса цитаты `#e0e2e6`»** — в образце бар измерен как **`#b3c2e1`** (2 px). Палитра меняется осознанно: образец — главный ориентир, §3.6 разрешает смену «с обоснованием».
4. **В образце у одного узла две врезки.** Модель хранит **одну** врезку на ответ (снимок родителя). Несколько врезок = несколько узлов.
5. **§2 «шапка `#f5f6f7`»** — в образце фон шапки **чередуется по глубине**: 0 `#f5f6f7`, 1 `#f5f7fb`, 2 `#f5f6f7`. Реализуем чётность (см. §2). Также по образцу у карточек нет теней, а 32 px над шапкой — белый фон карточки.
6. В образце аватары — фотографии; решено иконками-инициалами (DESIGN §2).
