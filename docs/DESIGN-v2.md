# Дизайн каскада — контракт v2

**Замороженный вход.** Приведение интерфейса каскада к образцу из ТЗ.

Источник: `docs/task/page1-X10.png` (914×824). Любое расхождение с этим файлом — дефект.
Цвета сняты из образца программно, не на глаз. Точные размеры/отступы — мерить по образцу, приведённые ниже значения верны на 1–2 px.

## 2. Шапка записи — слева направо

| Элемент | Спецификация |
|---|---|
| Аватар | круг 40 px, цветной фон, **инициалы белым**, светлое кольцо 2 px. Фото не делаем — решено: инициалы |
| Имя | жирное, `#0a1833`, ~17 px |

| Голосование | прижато вправо: `↑` · число · `↓`, цвет `#848b99` |

### Иконки — порядок и смысл

Иконок ровно 4, порядок слева направо: `#` · закладка · ответ · **четвёртая неоднозначна**.

| № | Иконка | Трактовка | Поведение |
|---|---|---|---|
| 1 | `#` | якорная ссылка на запись | прокрутка + якорь в URL |
| 2 | 🔖 | закладка | клиентская, `localStorage` |
| 3 | `↳` | ответить | раскрывает форму ответа на эту запись |
| 4 | ⓘ | информация об авторе | всплывающая карточка: имя, e-mail, IP, сайт автора |

Четвёртая иконка читается и как «информация», и как «перейти на сайт автора». Выбрать одну трактовку и зафиксировать её в `docs/`.

### Чего в шапке быть не должно

**Убрать как видимый текст:** e-mail, IP-адрес, «домашняя страница».
Они собираются по ТЗ, но в образце их в шапке нет. Все три доступны через иконку №4.

## 3. Голосование — только внешний вид

`↑ 0 ↓` по образцу. **Бэкенд не трогать, состояние не сохранять.**
Элемент декоративный, помечен как неинтерактивный (`aria-hidden` либо неактивные кнопки). В `docs/` отметить, что голосование в ТЗ отсутствует и добавлено исключительно ради соответствия образцу.

## 4. Цитаты — функциональные

Ответ **хранит врезку текста родителя**, зафиксированную на момент создания ответа.

**Бэкенд**
- при `parentId != null` сохранять плоский текст родителя в отдельном поле (например, `QuotedText`)
- плоский текст = HTML без тегов, пробелы схлопнуты, entities раскрыты
- обрезка до ~160 символов по границе слова + символ `…`
- поле аддитивное: замороженный `docs/API-v2.md` **не ломать**, поле необязательное
- обновить `db/schema.sql`, `db/schema.md` и файл схемы для MySQL Workbench, если он есть
- **экранировать при выводе** — врезка не должна открывать XSS

**Фронтенд**
- рендер: тонкая вертикальная полоса слева ~3 px, цвет `#e0e2e6`, отступ текста ~12 px
- текст цитаты `#848b99`, **не курсив**
- полоса стоит на том же уровне, что и обычный текст тела (это не двойной отступ вложенности)
- если цитата длиннее — обрезка с `…`

## 5. Вложенность

- каждая запись = своя полоса-шапка + тело
- отступ ребёнка ~40 px; **шапка ребёнка сдвинута так же**, как и тело
- линия вложенности слева: `#e0e2e6`
- глубина не ограничена
